# Solitude

> *Outwork everyone. Outplay everyone.*

**Solitude** is a competitive Fortnite training bot built for Discord. Track your grind, log results, review VODs, save strategies, and level up as a team — all in one place.

## ✨ Features

### 🏋️ Training & Grind
- `/grind start` / `/grind end` — Track training sessions with focus areas and self-ratings
- `/grind stats` — View your grind time, streaks, and consistency
- `/warmup` — Get randomized warmup routines (aim, builds, edits, box fights)
- `/goal set` / `/goal check` — Set and track personal training goals

### 🏆 Competitive & Results
- `/result` — Log match results (placement, kills, points)
- `/tournament` — Log full tournament results with analysis
- `/stats` — Live Fortnite player stats from Epic Games
- `/leaderboard` — Server rankings (kills, results, grind hours)

### 🔍 Review & Improvement
- `/vod` — Submit VOD reviews with clip links and timestamps
- `/fix` — Track recurring mistakes with priority levels
- `/strategy` — Build a team strategy library (rotations, zone plays, fights)
- `/drop` — Save drop spots with loot routes and map links

### 📡 Competitive Intel
- Auto-posted BR news and patch notes
- Fortnite map updates
- Live player stats from fortnite-api.com

### ⚙️ Server Management
- `/setup` — Configure feature channels per server
- `/language` — Multi-language support (English, Russian, and more)
- `/help` — Full command reference

## 🌍 Multi-Language
Solitude supports multiple languages out of the box. Server admins can switch with `/language`.

## 🚀 Built For Teams
Every team gets isolated data — your strategies, results, and training logs stay private to your server.
